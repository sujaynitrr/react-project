# React + Parcel Starter

A lightweight React project setup using [Parcel](https://parceljs.org/) as the bundler — built from scratch without using Create React App.

This setup includes:

- ✅ Manual project structure (no `npx create-react-app`)
- ⚛️ React and ReactDOM installed via npm
- 🚀 Parcel for fast development and easy bundling
- 🧩 Minimal configuration, fast startup

## Why this repo?

This starter is perfect for:

- Learning how React works without the abstraction of CRA
- Building small apps or prototypes with minimal tooling
- Gaining a deeper understanding of bundlers like Parcel
